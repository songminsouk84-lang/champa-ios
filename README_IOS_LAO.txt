- ຊື່ແອັບ: Champa

- ແຫຼ່ງຂໍ້ມູນ: https://sites.google.com/view/bolchvoice/champa

## ວິທີເປີດໃນ Xcode (ເທິງ Mac)
1. ຕິດຕັ້ງ XcodeGen: brew install xcodegen
2. ຣັນຄຳສັ່ງໃນໂຟນເດີນີ້: xcodegen generate
3. ດັບເບິ້ນຄລິກເປີດໄຟລ໌ Champa.xcodeproj ດ້ວຍ Xcode
4. ເລືອກ Team / Signing ຂອງທ່ານ ແລ້ວກົດ Run ລົງ iPhone ຫຼື Archive ຂຶ້ນ App Store ໄດ້ເລີຍ!

## ວິທີຕິດຕັ້ງໄຟລ໌ .IPA ທີ່ໄດ້ຈາກ Cloud Build
- ໃຊ້ໂປຣແກຣມ Sideloadly, AltStore, ຫຼື TrollStore ເພື່ອຕິດຕັ້ງໄຟລ໌ Champa.ipa ລົງໃນ iPhone/iPad.
